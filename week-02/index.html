03 / Basic data types

Basic data types

A value has a type. The type determines which operations make sense and how the value behaves.

TypePurposeExample
intWhole numberscount = 5
floatFloating-point numberstemperature = 5.0

Practice / Inspect a value

Type and behavior 
value = 5
print(type(value).__name__)
print(value + value)
Printed outputint 10

Integers support arithmetic. Adding two 5 values produces 10.

A name can be reassigned to a value of a different type. "False" is non-empty text, not the Boolean False. bool("False") returns True; converting user answers requires an explicit rule.

Most decimal fractions are approximations in binary floating point. For example, 0.1 + 0.2 may display 0.30000000000000004. Output formatting changes the display, not the stored value.

04 / Input, conversion, and output

Input, conversion, and output

input() returns text. Convert that text to the numeric type required by the problem before calculating.

Conversion rules

int("12")      # 12
float("12.5")  # 12.5
int("12.5")    # ValueError

int() cannot parse a decimal point in a string. int(12.9) truncates a numeric value toward zero; it does not round it.

Formatted output

temperature = 21.5
print(f"Celsius: {temperature:.1f}")

An f-string inserts expressions inside braces. :.1f displays one digit after the decimal point. Python uses a dot for decimal input in these examples.

06 / Comparisons and Boolean logic

Comparisons and Boolean logic

Comparisons produce True or False. Combine conditions with and, or, and not to express a rule.

Comparison

score == 60
score != 60
score >= 60

Other comparisons: <, <=, >. == compares values; = assigns a value.

and / or

For Boolean operands, and requires both to be True. or requires at least one to be True.

not

not reverses a Boolean result. Parentheses make the intended grouping explicit.

09 / Shipping exercise and recap

Shipping exercise and recap

Combine a multi-branch rule with a separate membership discount. Define the input domain before writing the algorithm.

Classroom shipping rules

Weight must be greater than 0 and at most 10 kg. Up to 2 kg costs 5 credits; above 2 and up to 5 kg costs 8; above 5 and up to 10 kg costs 12. Members receive a 2-credit discount. Invalid weight produces Invalid weight.

Write the inputs and output, pseudocode, a flowchart, and Python. Test 2, just above 2, 5, just above 5, 0, and 10; compare member and non-member results.

Practice / Check a shipping prediction

Classification + discount
Printed output—
Predict the price before checking. Inputs 0 and above 10 test invalid weight.
Reveal the worked solution 
INPUT weight, member
IF weight ≤ 0 OR weight > 10 THEN
    OUTPUT "Invalid weight"
ELSE
    IF weight ≤ 2 THEN
        cost ← 5
    ELSE IF weight ≤ 5 THEN
        cost ← 8
    ELSE
        cost ← 12
    END IF
    IF member THEN
        cost ← cost - 2
    END IF
    OUTPUT cost
END IF
weight = float(input("Weight (kg): "))
member = input("Member (yes/no): ") == "yes"
if weight <= 0 or weight > 10:
    print("Invalid weight")
else:
    if weight <= 2:
        cost = 5
    elif weight <= 5:
        cost = 8
    else:
        cost = 12
    if member:
        cost -= 2
    print(f"Shipping: {cost} credits")

Shipping flowchart

The discount is a separate if because it applies after any valid weight category. In the script, only the exact input yes enables membership. The preview uses a checkbox for the same Boolean value.

11 / Math library

Math library

The math module provides mathematical functions and constants. Import it once, then access its names with math.name. It is included with Python.

Import and call

import math

print(math.sqrt(9))  # 3.0
print(math.pi)       # 3.141592653589793

Built-in or module function?

abs(), round(), and len() are built-ins. math.sqrt() and math.floor() require the import. math.pi is a constant, so it has no call parentheses.

NameMeaning
math.sqrt(x)Non-negative real square root
math.floor(x)Greatest integer at or below x
math.ceil(x)Smallest integer at or above x
math.trunc(x)Remove the fractional part toward zero
math.factorial(n)n! for a non-negative integer; 0! = 1
math.pi / math.eConstants π and e
math.radians(degrees)Convert degrees to radians
math.sin(x) / math.cos(x)Trigonometric functions; x is in radians
math.hypot(a, b)Distance √(a² + b²)
