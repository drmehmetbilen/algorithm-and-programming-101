append versus extend

a = [1, 2]
a.append([3, 4])
print(a)  # [1, 2, [3, 4]]

b = [1, 2]
b.extend([3, 4])

remove versus pop

scores = [72, 85, 72]
result = scores.remove(72)
print(result)  # None
print(scores)  # [85, 72]
last = scores.pop()
print(last)    # 72
print(scores)  # [85]

sort versus sorted

scores = [91, 72, 85]
ordered = sorted(scores)
print(scores)   # [91, 72, 85]
print(ordered)  # [72, 85, 91]
result = scores.sort()
print(result)   # None
print(scores)   # [72, 85, 91]

Dictionaries and records

Use a key to access a value. In a dictionary, in checks keys, and get() can supply a default for a missing key.

Lab / Read and update a record

Printed output—
Keys are unique. Assigning an existing key replaces its value.

Preview limit: 8 keys. Keys are strings; values are strings or whole numbers.

A missing key

student = {"name": "Ada"}
print(student.get("city", "Unknown")) # Unknown
print(student.get("city"))            # None
print("city" in student)              # False
# student["city"] raises KeyError

Membership checks keys

student = {"name": "Ada", "score": 90}
print("name" in student)           # True
print("Ada" in student)            # False
print("Ada" in student.values())   # True
print(list(student.keys()))        # ['name', 'score']

Update, insert, delete

student = {"name": "Ada", "score": 90}

student["city"] = "Ankara"
del student["city"]

Access nested values

08 / References and copies

References and copies

Assignment gives another name to the same object. Compare it with copy() one line at a time.

Trace / Two names, which objects?

  1. scores = [80, 90]
  2. backup = scores
  3. scores.append(100)
  4. print(scores)
  5. print(backup)
  6. print(scores is backup)

Variables and objects

Printed output—
Step through the code and follow the values.

Object labels identify objects in the diagram; they are not real memory addresses. is checks identity; == compares values. A shallow copy creates a new outer collection and shares references to its items.

Equal values, distinct lists

a = [80, 90]
b = a.copy()
print(a == b)  # True
print(a is b)  # False
b[0] = 0
print(a)       # [80, 90]
print(b)       # [0, 90]

A new outer list, shared inner list

groups = [[80, 90], [70]]
backup = groups.copy()
backup[0].append(100)
print(groups[0])            # [80, 90, 100]
print(groups is backup)     # False
print(groups[0] is backup[0]) # True
